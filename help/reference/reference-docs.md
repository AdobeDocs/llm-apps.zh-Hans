# 操作和构件字段 {#action-widget-configuration}

>[!IMPORTANT]
>
>[!DNL Adobe LLM Apps]当前在Beta中。
>
>此处显示的功能、工作流和UI不一定表示产品的最终状态。 要加入Beta，请发送电子邮件至llm-apps-beta@adobe.com 。

使用此页可在操作编辑器中查找字段。 有关创建步骤，请参阅[从头开始创建操作](/help/guides/create-action.md)。

## 查找设置

**[!UICONTROL 创建新操作]**&#x200B;对话框具有&#x200B;**[!UICONTROL 操作]**&#x200B;和&#x200B;**[!UICONTROL 小组件元数据]**&#x200B;选项卡。

创建后，保存操作编辑器将使用三个选项卡：

| 选项卡 | 设置 |
|---|---|
| **[!UICONTROL LLM构件详细信息]** | 构件类型、沙盒域、构件描述、模板URL和CSP |
| **[!UICONTROL 操作详细信息]** | 代码标识符、描述、输入参数和&#x200B;**[!UICONTROL LLM设置]**，包括注释、调用状态文本和可见性 |
| **[!UICONTROL 分析]** | 用户意图收集和说明 |

要保存您的编辑，请选择&#x200B;**[!UICONTROL 保存更改]**。 正在等待审阅的生成操作改为显示&#x200B;**[!UICONTROL 标记为已审阅]**，它也处理其生成的拉取请求。

## 操作参数

输入参数是LLM平台发送到操作处理程序的值。 该模型从用户消息中提取值并将它们映射到配置的参数。

| 属性 | 描述 |
|----------|-------------|
| **名称** | 参数标识符（例如，`category`，`query`） |
| **类型** | `String`、`Number`、`Integer`或`Boolean` |
| **描述** | 易于用户识别的解释 — LLM平台使用该解释来提取正确的值 |
| **必需** | 如果选中，则在调用操作之前，模型必须提供此参数 |

### 文件参数

文件参数是在操作编辑器中配置的输入字段名称。 当用户上传文件时，主机会为这些参数（通常包括`download_url`和`file_id`）提供文件对象。

## 元数据字段

### 基本信息

| 字段 | 必需 | 描述 |
|-------|----------|-------------|
| **操作名称** | 是 | 操作的显示名称（例如，*搜索产品*） |
| **描述** | 是 | 操作功能的说明 — LLM平台使用说明来决定何时调用操作 |

创建对话框预览从操作名称派生的不可变&#x200B;**代码标识符**。 它在应用程序内是唯一的，最多可包含63个字符，并且以小写字母开头，使用小写字母、数字、连字符或下划线。 它将操作映射到处理程序存储库中的`actions/<code-identifier>/index.js`。

### 注释

描述操作行为的可选提示：

| 注释 | 描述 |
|------------|-------------|
| **破坏性提示** | 该操作可能会删除或覆盖数据 |
| **幂等（相同的参数=无额外效果）** | 重复相同的请求不会对环境产生额外影响；重复请求不一定返回相同的数据 |
| **Open World提示** | 该操作与外部系统交互 |
| **只读提示** | 该操作只读取数据，从不写入 |

### OpenAI元数据

| 字段 | 最大长度 | 描述 |
|-------|------------|-------------|
| **正在调用状态文本** | 64个字符 | 运行操作时在LLM平台中显示的消息（例如，*正在加载产品……*） |
| **调用状态文本** | 64个字符 | 操作完成后显示的消息（例如，*产品已加载……*） |
| **构件描述** | 512个字符 | 映射到`_meta["openai/widgetDescription"]`；汇总模型的渲染组件并减少重复的旁白 |

操作描述控制模型何时选择操作。 构件描述说明了组件在呈现之后显示的内容。

### 可见性

要打开或关闭某个操作，请在应用程序页面上使用其&#x200B;**[!UICONTROL 可见性]**&#x200B;开关。 交换机控制下一个部署是否包括操作。 操作编辑器没有单独的开/关开关。

以下操作编辑器设置可控制模型和小组件曝光，而不是应用程序级别的打开/关闭状态：

| 切换 | 描述 |
|--------|-------------|
| **公开给AI模型** | AI模型可在对话期间调用操作 |
| **在应用程序表面中显示为小组件** | 操作在应用程序中呈现可视化构件 |

模型和小组件曝光设置不会取代选择小组件类型。

### 分析

| 字段 | 描述 |
|-------|-------------|
| **收集用户意图** | 默认启用。 请求导致执行分析操作的目标匿名摘要 |
| **用户意图描述** | 用于请求摘要的说明（最多2,000个字符）。 默认值不包括个人和敏感信息。 查看针对您的隐私策略的任何自定义 |

## 构件字段

### 构件信息

| 字段 | 描述 |
|-------|-------------|
| **类型/构件类型** | 在创建对话框中，选择&#x200B;**[!UICONTROL Edge Delivery Services块]**&#x200B;或&#x200B;**[!UICONTROL 无构件]**。 保存的编辑器为纯文本选项&#x200B;**[!UICONTROL 无交互式UI]**&#x200B;添加了标签 |
| **构件域** | 主机使用的沙盒源。 UI会根据应用程序提交的要求来标识它，并且每个应用程序具有唯一性。 这独立于EDS页面的&#x200B;**小组件URL** |
| **首选边框** | 请求带边框的容器；渲染取决于主机。 在“创建”对话框中可用 |

### 模板URL

| 字段 | 描述 |
|-------|-------------|
| **[!UICONTROL 脚本URL]** | EDS `scripts/aem-embed.js`入口点的HTTPS URL。 在同一EDS项目中跨操作共享 |
| **小组件URL** | 操作呈现的EDS页面的HTTPS URL。 生成的操作会自动配置URL |

## CSP配置

内容安全策略控制构件iframe可以联系哪些外部域。 每个外部域都必须明确列入允许列表。

| 指令 | 描述 |
|-----------|-------------|
| **资源域** | 静态资产的域 — 图像、字体、脚本、样式 |
| **连接域** | 构件可能通过`fetch`、`XHR`或`WebSocket`联系的域 |
| **帧域** | 允许嵌套iframe的源；触发更严格的应用程序审核 |
| **重定向域** | `openExternal`个重定向链接的受信任目标（特定于[!DNL ChatGPT]） |
| **基本URI域** | `base-uri` CSP指令（仅MCP应用SDK，而不是[!DNL ChatGPT]） |

## 权限

构件权限可管理对硬件和浏览器API的访问。 权限映射到iframe权限策略。

权限控件显示在创建对话框的&#x200B;**[!UICONTROL 权限（特定于MCP）]**&#x200B;下。 仅授予构件所需的功能；主机支持和用户同意也适用。

| 权限 | 描述 |
|------------|-------------|
| **摄像头** | 访问设备摄像头 |
| **麦克风** | 访问设备麦克风 |
| **地理位置** | 访问用户的位置 |
| **剪贴板** | 从剪贴板读取或写入剪贴板 |
