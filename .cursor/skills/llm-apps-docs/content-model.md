# 内容模型和术语

## 内容类型

### 教程

指导新用户完成一个完整的成功历程。

- 说明结果和先决条件。
- 使用一个示例应用程序和一个序列。
- 仅说明每个步骤所需的概念。
- 以工作结果结束，并明确后续步骤。

主教程： `help/guides/create-app.md`。

### 概念

说明零件如何关联，而不成为过程或字段目录。

- 关注心智模式和所有权界限。
- 使用小图表可增进理解。
- 链接到教程、操作指南和参考。

### 操作指南

帮助消息灵通的用户完成一项任务。

- 从所需的结果开始。
- 仅包括特定于任务的先决条件。
- 首选推荐的路径。
- 用于引用详尽字段的链接。

示例：从头开始创建操作、自定义构件、引进EDS项目、部署和测试。

### 引用

提供用户工作时可查阅的事实信息。

- 按产品或代码表面组织。
- 精确地定义每个字段、合同、命令、限制和状态。
- 避免使用教程叙述和重复的示例。

### 疑难解答

从可观察的症状开始。

- 描述可能的原因。
- 提供安全的诊断步骤。
- 避免要求用户泄露凭据或敏感日志。

## 规范术语

- **Adobe LLM应用程序** — 首次提及的完整产品名称。
- **LLM应用程序** — 一个由产品管理的应用程序。
- **载入代理** — 创建初始基架的功能。
- **构建我的应用程序** — “创建应用程序”对话框中的UI部分。
- **自动构建我的应用程序** — 确切的复选框标签。
- **操作** — 对LLM平台公开的功能。
- **操作元数据** — 由LLM应用程序存储的名称、描述、架构、注释、可见性和构件配置。
- **操作处理程序** — 处理程序存储库中的服务器端函数。
- **处理程序存储库** — 包含处理程序和测试的存储库。 仅在描述该控件时才使用UI标签&#x200B;**样板存储库**。
- **EDS存储库** — 包含小组件块和内容的存储库。
- **小组件** — 在LLM平台中呈现的可视响应。
- **MCP服务器URL** — 已部署终结点已在LLM平台上注册。
- **ChatGPT插件** — 从MCP服务器URL创建的ChatGPT集成。
- **暂存**&#x200B;和&#x200B;**生产** — 部署环境。

除非对MCP协议的详细信息进行了说明，否则避免在面向用户的文章中的“tool”和“action”之间进行切换。

## 推荐的读者历程

1. 概述和先决条件。
2. 使用载入代理创建应用程序。
3. 查看生成的操作。
4. 部署到暂存并测试ChatGPT插件。
5. 自定义生成的处理程序和小组件。
6. 将自定义应用程序部署到生产环境。

从头开始创建操作并引入EDS项目是高级分支，而不是默认的首次运行历程。
