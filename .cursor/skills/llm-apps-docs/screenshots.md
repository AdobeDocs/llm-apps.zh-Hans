# 生产屏幕快照过程

您可以使用此过程从以下位置捕获真正的公共文档屏幕截图：

`https://experience.adobe.com/#/@llmapps/llm-apps/`

优选的工作流程是人工捕获，然后是代理辅助摄取。 用户可决定哪些生产状态相关；该技能可整理、整理它们并将其集成到文档中。

## 捕获收件箱

将每次捕获运行放在：

```text
docs-captures/<YYYY-MM-DD>/
```

Git将忽略该目录。 原始屏幕截图必须保留在本地且不得提交。

用户可以使用任何文件名，但按顺序命名更容易查看：

```text
01-create-app.png
02-connect-github.png
03-onboarding-enabled.png
04-generating-actions.png
05-review-actions.png
```

可选的`capture-notes.md`可以描述缺少的状态、异常行为或预期顺序。

## 安全边界

- 用户直接在浏览器中输入Adobe、GitHub和LLM平台凭据。
- 停止以获取MFA、密钥、captcha、组织选择和特权同意。
- 绝不读取、打印、保存或提交令牌、Cookie、浏览器存储或凭据。
- 使用非敏感的公共网站和新的仅用于文档的存储库。
- 仅向夹具使用的两个存储库授予GitHub应用程序访问权限。
- 在创建、部署、删除、存档或更改存储库访问权限之前询问。
- 不捕获个人信息、组织ID、存储库安装ID、令牌或完整运行时URL。

## 夹具命名

使用明确标识可处置文档资源的名称：

```text
App: LLM Apps Docs <YYYY-MM-DD>
Handler repo: llm-apps-docs-<YYYYMMDD>
EDS repo: llm-apps-docs-<YYYYMMDD>-eds
```

在创建任何内容之前，请先确认目标Adobe组织、GitHub所有者、公共网站以及用户的夹具名称。

创建空存储库和专用存储库。 不要使用README、许可证或`.gitignore`初始化它们。

## 捕获设置

- 请使用足够大的桌面视区，以便显示完整的对话框，而无需使用浏览器铬版。
- 保持缩放为100%。
- 除非文章专门教授主题，否则请使用默认的产品主题。
- 捕获包含任务和必要上下文的最小完整区域。
- 避免使用游标、打开与步骤无关的菜单、来自先前操作的祝酒词以及临时旋转器（除非旋转器是文档状态）。
- 使用PNG。
- 保持文件名稳定；在刷新期间替换图像内容而不是重命名文件。

## 建议的捕获序列

用户应从清单中捕获相关状态，包括：

1. 在连接GitHub之前创建应用程序。
2. GitHub应用程序存储库访问权限选择。
3. **自动构建我的应用程序**，并选择了两个存储库。
4. 应用程序创建或自动应用程序构建启动。
5. 正在生成的操作。
6. 生成的操作可供审查。
7. 一个代表性操作的元数据、处理程序和小组件。
8. 每个操作审查和所有操作审查状态。
9. 成功暂存部署。
10. LLM平台中的应用程序注册和代表结果。

当其他屏幕解释实际决策、错误或先决条件时，请捕获这些屏幕。 不要捕获每次点击。

## 技能输入工作流

当用户要求从捕获文件夹更新文档时：

1. 确认确切的捕获目录。
2. 清点所有PNG、JPEG和WebP文件，并直观地检查每个图像。
3. 生成从源文件到`screenshot-manifest.md`中条目的映射。
4. 将可见的UI标签和序列与现有教程进行比较。
5. 报告：
   - 缺少必需状态；
   - 重复或冗余的图像；
   - 排序模糊；
   - 过时的屏幕截图；
   - 敏感信息；
   - 与文档冲突的生产行为。
6. 不编辑源捕获。
7. 对于每个接受的图像，使用`help/assets/guide-onboarding-agent/`下的稳定清单文件名创建一个经过清理的副本。
8. 仅当周围的UI未添加有用的上下文时裁切。
9. 隐藏敏感值。 如果无法进行安全屏蔽，请要求重新捕获。
10. 更新文章和替换文本以匹配捕获的工作流。
11. 运行链接和资产验证。
12. 在用户明确要求删除捕获文件夹之前，请将其保留在原处。

## 可选代理引导式捕获

如果用户要求代理驱动浏览器，请使用相同的清单和安全边界。 暂停以进行身份验证、特权同意、存储库更改、应用程序创建、部署和清理。 切勿在无人值守的情况下运行此生产突变流。

## 图像审核

对于每个图像：

- 将其与一个清单条目匹配。
- 根据文章验证UI副本。
- 在不需要帐户导航时裁剪帐户。
- 屏蔽个人名称、头像、组织标识符、存储库安装标识符、运行时命名空间和不相关的应用程序。
- 确认浏览器自动填写、电子邮件、访问令牌或专用存储库详细信息不可见。
- 编写同时标识屏幕和状态的替换文本。

## 何时停止

在以下情况下停止并报告阻止程序：

- 生产与记录的工作流不匹配。
- 审阅流程与发布的文档有很大不同。
- 存储库验证拒绝预期的空存储库流。
- 载入管道失败。
- 特权操作需要用户或管理员。
- 如果不隐藏对步骤至关重要的信息，则屏幕截图将无法保持安全。
