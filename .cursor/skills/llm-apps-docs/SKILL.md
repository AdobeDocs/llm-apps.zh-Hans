# LLM应用程序文档

为Adobe LLM应用程序创建面向任务的可验证公共文档。

## Source-of-truth顺序

按以下顺序验证产品声明：

1. 当前生产UI位于`https://experience.adobe.com/#/@llmapps/llm-apps/`
2. 工作区中可用的当前UI和API实施
3. 当前公共SDK和样板行为
4. 现有公共文档

如果“生产”与来源或计划冲突，请记录“生产”并报告不匹配。 不要发布当前可用的即将到来的工作流。

## 开始每项任务

1. 读取`help/main-toc/TOC.md`。
2. 阅读目标文章和直接相关的文章。
3. 使用[content-model.md](content-model.md)对内容进行分类。
4. 确定需要验证的UI标签、URL、命令和合同。
5. 保持页面间的端到端示例和术语一致。

## 创作规则

- 通过载入代理引导首次访问用户。
- 组织关于用户历程和结果的导航，而不是实施主题。
- 在每个指南的开头附近说明旅程序列，并提供下一个共享步骤。
- 将&#x200B;**入门代理程序**&#x200B;用于产品功能和确切的UI副本，例如&#x200B;**[!UICONTROL 自动构建我的应用程序]**&#x200B;用于控件。
- 当用户首次遇到某个技术概念时对其进行解释；链接到更深入的概念或参考资料。
- 使教程保持线性，使用方法指南以任务为中心，并参考页面事实。
- 仅包括读者当前任务所需的信息；偏好短而直接的句子。
- 在整个历程中使用一个代表性应用程序。
- 将生成的基架与生产就绪型集成区分开来。
- 避免使用内部工作程序名称、数据库字段、实施票证以及不稳定的管道详细信息。
- 不要在参考线之间复制字段表；链接以供参考。
- 保留Experience League前件和指令： `[!DNL]`、&grave;&grave;、`[!IMPORTANT]`、`[!NOTE]`和`[!TIP]`。
- 使用根相对内部链接： `/help/...`。
- 标题和标题使用句子大小写，除非产品标签另有要求。
- 使用说明性图像替代文本，说明屏幕和状态。

## 安全要求

- 绝不要包含凭据、令牌、私有URL、个人数据、内部主机名或客户标识符。
- 显示从托管配置加载的密钥，从不进行硬编码。
- 外部服务需要HTTPS。
- 验证外部输入和上游响应。
- 使用安全DOM API呈现外部值；建议不要将其插入到`innerHTML`中。
- 推荐最低权限的GitHub应用程序、API、CSP、CORS和浏览器权限。
- 使用安全的面向用户的错误并避免记录敏感数据。

## 屏幕快照工作流

对于新图像或更新的图像，请遵循[screenshots.md](screenshots.md)和[screenshot-manifest.md](screenshot-manifest.md)。

默认工作流使用用户创建的生产捕获包：

1. 查找`docs-captures/<run-id>/`下的屏幕截图，或使用用户提供的文件夹。
2. 清点并直观检查每个PNG、JPEG和WebP文件；不要仅依赖其文件名。
3. 匹配屏幕截图，以显示使用可见UI内容的状态。
4. 在更改文档之前，报告缺失、重复、不明确、过时或不安全的捕获。
5. 保留源捕获不变。
6. 使用`help/assets/`下的稳定清单文件名创建经过清理的最终副本。
7. 更新教程和相关指南，以匹配实际捕获的生产工作流。
8. 添加准确的替换文本并运行文档验证。

代理引导式浏览器捕获仍是一个可选的回退方案。 请勿存储浏览器状态或凭据，也请勿在CI中运行生产突变屏幕快照捕获。

当系统要求“通过屏幕截图更新文档”时：

- 将最新明确选定的捕获文件夹视为源。
- 仅当应用程序流程或屏幕快照映射真正模糊时才询问。
- 从不提交原始捕获文件夹。
- 未经明确批准不得删除或修改源捕获。
- 如果敏感信息无法在不影响任务的情况下删除，请请求安全的重新捕获。

## 构建审阅存档

生成可共享的离线HTML站点和ZIP存档：

```bash
node .cursor/skills/llm-apps-docs/scripts/build_review_bundle.mjs
```

内部版本写在存储库旁边，而不是存储库内部。 它仅包括
已发布的文章和经过清理的资源，可转化Experience League指令
进行离线审阅，并注意其样式不是最终体验
联盟呈现。

## 验证

运行：

```bash
python3 .cursor/skills/llm-apps-docs/scripts/validate_docs.py
```

在交付之前，修复每个缺失的内部文章、缺失的资产、无效的根相对路径以及缺失的前台字段。

另请检查：

- UI标签和屏幕截图与生产环境相匹配。
- 脚本和小部件URL示例在指南和参考中是一致的。
- 命令与当前样板匹配。
- 新页面将从目录中链接。
- Adobe文章验证工作流在可用时通过。
